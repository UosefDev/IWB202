مساعد اختيار السيارة الذكي

Smart Car Recommendation Assistant


إعداد: فريق DriveEasy — مادة تصميم وتطوير تطبيقات الوب — 2026

📋 ملخص الفكرة

اسم الـ Feature مساعد اختيار السيارة الذكي (Smart Car Advisor)
الهدف مساعدة الزبون في اختيار السيارة الأنسب بناءً على احتياجاته وميزانيته
المستخدم المستهدف الزبون / الزائر للموقع
نوع التقنية المستخدمة معالجة اللغة الطبيعية (NLP) + نظام توصية قائم على المحتوى

🎯 الهدف من الفكرة

كثير من الزبائن يجدون صعوبة في اختيار السيارة المناسبة من بين قائمة كبيرة من الخيارات المتاحة، خصوصاً عندما لا يكون لديهم خبرة تقنية كافية في مقارنة المواصفات.

هذه الميزة تهدف إلى تبسيط عملية الاختيار من خلال طرح أسئلة بسيطة على الزبون (عدد الأشخاص، الميزانية، نوع الاستخدام، مدة التأجير)، ثم تقديم توصية ذكية بالسيارة الأنسب له، مع شرح سبب التوصية.

⚙️ وصف طريقة عمل الميزة

1
الزبون يكتب طلبه بلغة طبيعية

مثلاً: "أحتاج سيارة لـ 4 أشخاص، لرحلة 5 أيام، ميزانيتي 1,200,000 ل.س" أو يجيب على أسئلة موجَّهة ضمن نموذج حوار بسيط (Chatbot).

2
تحليل الطلب بتقنية NLP

يُرسَل النص إلى نموذج لغوي (مثل OpenAI GPT API أو Gemini API) لاستخراج المعطيات الأساسية: عدد الركاب، الميزانية، نوع الاستخدام (مدينة/سفر).

3
مطابقة المعطيات مع قاعدة بيانات السيارات

يُقارن النظام المعطيات المستخرجة مع مواصفات وأسعار السيارات المتوفرة باستخدام خوارزمية تصفية وترتيب (Filtering + Scoring).

4
عرض التوصية

يُعرض على الزبون ترتيب أفضل 1-3 سيارات مناسبة، مع توضيح سبب التوصية، وزر مباشر لتحديد السيارة وبدء الحجز.

🔧 خطوات التنفيذ

  1. تصميم واجهة الحوار (Chat UI): إضافة زر "ساعدني في الاختيار" في صفحة السيارات يفتح نافذة Chatbot بسيطة.
  2. ربط الواجهة بـ API للذكاء الاصطناعي: استخدام Fetch API في جافاسكريبت لإرسال رسالة الزبون إلى OpenAI GPT-4o API أو Google Gemini API.
  3. System Prompt مُخصَّص: إرسال قائمة السيارات المتوفرة كـ context للنموذج اللغوي، مع تعليمات للرد باللغة العربية وتقديم توصية محددة.
  4. عرض النتيجة وربطها بالجدول: عند اقتراح سيارة معينة، يُضاف زر "اختر هذه السيارة" يُؤشّر خانة الاختيار مباشرةً في جدول السيارات.

💡 ملاحظات تقنية

التقنيات المستخدمة في التنفيذ:

OpenAI GPT-4o API 🌐 Fetch API (JavaScript) 📝 NLP — Natural Language Processing 🔍 Content-Based Filtering 💬 Chatbot UI 🔒 API Key (Backend Proxy)
  • مفتاح الـ API يجب أن يُخزَّن في جانب الخادم (Backend) لحمايته من الكشف.
  • يمكن استخدام Netlify Functions أو Vercel Edge Functions كـ proxy بسيط.
  • في حال الرغبة بعمل الميزة بدون API خارجي، يمكن بناء نظام توصية بسيط بجافاسكريبت يعتمد على قواعد ثابتة (Rule-Based System).
  • يُنصح بإضافة حد أقصى لعدد الطلبات لتجنب تجاوز حصة الـ API المجانية.
